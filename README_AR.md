# EX™ ARABIA STRIKE — EXPERIENCE 004

MVP Production-ready browser prototype for an **original** Arabian run-and-gun pixel action game.

## IP direction
This project deliberately does **not** include Metal Slug/SNK sprites, audio, maps, UI, bosses, characters, logos, code, or copied stage layouts. It uses the genre language (run-and-gun, pixel animation, pickups, vehicles, bosses, rescue loops, co-op) to create an original EX™ game universe.

## Included
- Browser Canvas 2D engine; no external libraries.
- 1280×720 logical pixel-art renderer.
- Desktop + touch controls.
- Original EX hero pixel avatar.
- Original armored 4×4 vehicle: EX-HMV.
- PULSE MG, SCATTER, ARC ROCKET, PRISM LASER.
- Grenades / explosive particles / screen shake.
- Fictional BLACK NODE raiders.
- Prisoner rescue / crate drops / secret route.
- DATE OVERDRIVE power-up.
- Giant DUNE HARVESTER boss.
- Local 2P keyboard co-op.
- Responsive HUD.
- PWA manifest + service worker.
- GitHub Pages compatible.

## Controls
### Player 1
- A / D — move
- W or Space — jump
- J or F — fire
- K — grenade
- E — enter / exit EX-HMV

### Player 2
- ← / → — move
- ↑ — jump
- / or Numpad 1 — fire
- . or Numpad 2 — grenade
- Enter — interact

### Mobile
On-screen controls are shown automatically.

## Deploy
Upload the contents of this folder to the root of a GitHub Pages repository and publish `main / (root)`.
